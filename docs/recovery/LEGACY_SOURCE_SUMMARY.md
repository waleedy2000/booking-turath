## 2. NOTIFICATION_SYSTEM.md
- **ماذا يغطي؟** النظام الشامل للإشعارات (Push و SMS) وآلية جدولتها وعمل الـ Cron Job.
- **المعلومات المفيدة:** مبررات استخدام Push بجانب SMS، هيكل رسائل الـ Push (إيموجي، تفاصيل كاملة)، قيود الـ SMS (لغة عربية، 70 حرفاً)، وآلية عمل الـ Cron Job كل 5 دقائق للبحث عن الحجوزات.
- **ما الذي أصبح قديمًا؟** الإشارة إلى Android SMS Gateway كمزود أساسي، الإشارة إلى Stage C بأنها قيد التنفيذ.
- **القرارات التي تغيرت:** اعتماد kwtSMS كبوابة SMS إنتاجية، وتخصيص Firebase/FCM للإشعارات Push فقط. تعديل رسالة التأكيد لـ 58 حرف والتذكير 63 حرف. قرار الإبقاء على Push مفصلة نظراً لعدم خضوعها لتكلفة SMS.
- **الاحتفاظ بالأرشيف:** نعم.
- **تفاصيل حساسة:** يحتوي على أسرار (مثل [REDACTED] الخاص بـ CRON_SECRET).
